#  Maze Generator & Escape Game (C)

A simple **console-based maze game in C** that generates a **random maze** using **DFS with Stack** and lets the player find a path from start to exit.

This was my first mini project in 2nd year while learning logic building and basic programming

---

 # Features

- Random maze on every run  
- DFS + Stack based maze generation  
- Keyboard controls (W A S D)  
- Start (S) and Exit (E) points  
- Move counter  

---

# Controls

W – Up | S – Down | A – Left | D – Right

---

# Tech Used

- C Programming  
- Stack, DFS, Backtracking  
- 2D Arrays & Structures  

---
# How to compile & Run

#On Windows(using g++)

g++ maze_game.c -o maze
